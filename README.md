# DISTANCE CALCULATOR
# DESCRIPTION
This program was made to find the distance between two points on a graph. 
# HOW TO RUN
1. Put it through a reliable IDE(VS Code, Google Collab, etc.)
2. Enter values for x1,x2,y1,y2
3. It will calculate with the formula distance = math.sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2))
# OUTPUT
Enter x1 = 2

Enter x2 = 3

Enter y1 = 4 

Enter y2 = 5

The distance of two points is: 5.9
